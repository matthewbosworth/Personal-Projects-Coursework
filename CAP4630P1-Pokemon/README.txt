Pokemon Colossuem Project README

Description:
This is a command line based Pokemon battle simulator game developed for CAP4630. The game implements an alternating turns based battle system where the player faces Team Rocket with randomly selected Pokemon teams made up of 3 unique Pokemon. The battle follows specific mechanics including type effectiveness, move management, and damage calculation.

Run using Python 3.11.5

PokemonColosseum.py - main game file
Pokemon.py - pokemon and move class definitions
moves-data.csv - move data provided by professor
pokemon-data.csv - pokemon data provided by professor
README.txt - this file

How to run the program
1. Open terminal or command prompt
2. Navigate to project directory
3. Run the game with 'python PokemonColosseum.py'

Or in Visual Studio Code
1. Open project folder
2. Open terminal
3. python PokemonColosseum.py

Game Controls
- Enter your team name when prompted
- Choose moves by entering 1-5
- Follow other on screen instructions
- Team Rocket's moves are handled by the game
